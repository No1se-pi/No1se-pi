## `$ ls ./projects`

### 🛡️ Custodes

**Pre-commit secret scanner**

A security CLI tool designed to catch sensitive data **before it reaches Git history**.

```text
git commit
    ↓
pre-commit hook
    ↓
Custodes
    ├── secret detection
    ├── entropy analysis
    ├── sensitive patterns
    └── security report
```

`Python` `Git Hooks` `Security Automation` `CLI`

---

### 👁️ Argus

**Monitoring & OSINT automation platform**

A project for monitoring public sources, posts, comments, mentions and activity across different platforms.

```text
Sources → Collectors → Analysis → Alerts → Dashboard
```

`Python` `Telethon` `OSINT` `Automation`

---

### 📊 SourceHealth

**Repository health & security scoring**

An experimental system that analyzes repositories and converts dozens of engineering and security signals into a single understandable score.

```text
Repository
   │
   ├── activity
   ├── documentation
   ├── maintainability
   ├── security
   ├── CI/CD
   └── community
          ↓
      Health Score
        0 — 100
```

`Code Analysis` `SAST` `Git` `Metrics` `Security`
